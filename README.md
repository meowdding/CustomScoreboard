Custom Scoreboard is a mod for modern Minecraft and Hypixel SkyBlock, inspired by [SkyHanni](https://modrinth.com/mod/skyhanni).
This mod lets you fully customize your scoreboard, making it easier to focus on the information that matters most while you're running a
Dungeon, slaying a Voidgloom or grinding for a Mineshaft in a Party!

Using /customscoreboard, or /cs for short, you can open the config and start customizing your Custom Scoreboard experience!

## Features

Features annotated with a ❇️ are new additions compared to the SkyHanni version.

<details>
<summary>Main Config</summary>

- ❇️ Hiding when Chat/F3/Tab is open.
- ❇️ Hoverable/Clickable Actions.

</details>

<details>
<summary>Appearance Config</summary>

- All Basic SkyBlock Lines.
- Additional Custom Lines:
  - Active Mayor & Minister
  - ❇️ Active Pet
  - Chunked Stats (Purse, etc. in one line)
  - Cookie Buff
  - Gems
  - ❇️ God Potion
  - Irl Time
  - Maxwell Tunings
  - Maxwell Power
  - Party Members
  - Powder/❇️ Whispers
  - Profile
  - Quiver
  - SkyBlock Level
  - ❇️ Slayer Stats
  - Soulflow
- ❇️ Tablist Widgets inside the Scoreboard.
- Custom Title/Footer Text.
- Scaling/Alignment.
- ❇️ Custom Prefixes for Currencies and co.

</details>

<details>
<summary>Background Config</summary>

- Background Color
- Padding/Margin/Corner Radius
- ❇️ Background Blurring
- ❇️ Min Width/Height
- Border Size and unique colors for each corner.
- Textured Background ❇️ with Gif support.
- ❇️ Background Image through ingame selector or config folder.

</details>

<details>
<summary>Lines Config</summary>

- Date Formatting and Lobby Code
- 12/24-Hour Time and Minute Display
- ❇️ Flight Duration Formatting
- Number and Currency Formatting
- Currency Gain, Available Bits, and Gems/Bank Formatting
- ❇️ Purse Display in Dungeons
- Slayer Level and Magical Power
- Quiver Arrow and Powder Display
- Profile Name and Party Members
- ❇️ Pet Prefix and Maximum Level
- Mayor, Minister, and Foxy Event Information
- Hiding Empty, Irrelevant, or Consecutive Lines
- Hiding Separators at the Start or End of the Scoreboard

</details>

<details>
<summary>Mod Compatibility</summary>

- ❇️ Custom Lines in [Scoreboard Overhaul](https://modrinth.com/mod/scoreboard-overhaul)
- ❇️ Scoreboard Overhaul border coloring based on SkyBlock Level
- Transferring the SkyHanni CustomScoreboard settings.

</details>

### Transferring from SkyHanni

You can easily transfer your config by using the ``Transfer`` button under `/cs` -> `Mod Compatibility`.
Your old SkyHanni Custom Scoreboard Background Texturepack will work fine, you won't need to update it.
